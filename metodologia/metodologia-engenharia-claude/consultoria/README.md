# Consultoria — Levar a Metodologia para Fora (decisão e implantação)

> **O que é esta pasta.** A camada da metodologia voltada **para fora do time técnico**: o material de
> decisão executiva e de implantação em qualquer empresa de software. As lentes didáticas (⚽/🏭)
> ensinam a metodologia a quem vai operá-la; a base conceitual guarda a substância neutra; **esta
> pasta responde às duas perguntas de quem decide e de quem implanta**: *"por que adotar?"* (com fatos
> e dados) e *"como implantar sem big-bang?"* (com fases, critérios de saída e templates).

| Documento | Pergunta que responde | Público |
|---|---|---|
| [Caso de Negócio](caso-de-negocio-cto.md) | *Por que adotar? Quais vantagens, com que evidência?* — dados de indústria (DORA 2025, METR, Faros), mecanismo → ganho, validação pelo modelo de capacidades do DORA, custos e riscos honestos | CTO, VP de Engenharia, liderança executiva |
| [Guia de Implantação](guia-implantacao.md) | *Como implantar?* — o que é portável × específico, pré-requisitos, 4 fases com critério de saída, templates mínimos, anti-padrões, modelo de maturidade | Líder técnico da implantação, consultor, curador de contratos |
| [Apresentação para CTO](apresentacao-cto-marp.md) | O caso de negócio em formato de reunião (deck Marp) | CTO e diretoria técnica |
| [Apresentação para Conselho](apresentacao-conselho-marp.md) | A decisão estratégica em linguagem de negócio, sem jargão técnico (deck Marp) | Conselho consultivo / board |

**Trilha sugerida para uma consultoria completa:** Caso de Negócio (decisão) → Guia de Implantação
(plano) → [Mapa da Governança](../base-conceitual/mapa-governanca.md) (anatomia do sistema de
referência) → lentes [⚽](../lente-futebol/README.md) / [🏭](../lente-engenharia-software/README.md)
(treinamento do time) → [Operar a Metodologia](../base-conceitual/operar-a-metodologia.md) +
[Indicadores](../base-conceitual/indicadores.md) (operação e medição).
